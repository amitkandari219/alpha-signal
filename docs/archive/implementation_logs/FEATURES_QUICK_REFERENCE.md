# Alpha Signal - Features Quick Reference

## 🎯 Core Features at a Glance

### 📊 Stock Analysis
- **50 Nifty 50 Stocks** - Complete coverage
- **AI Intelligence** - Bull/Bear cases, risks
- **5 Composite Scores** - Quality, Growth, Risk, Sentiment, Momentum
- **Real-Time Prices** - WebSocket live updates
- **Company Logos** - Multi-source fetching
- **Interactive Charts** - 8 timeframes (1D to MAX)

### 🔐 User Tiers

| Feature | FREE | PRO (₹499/mo) | PREMIUM (₹1,999/mo) |
|---------|------|---------------|---------------------|
| Watchlists | 1 (10 stocks) | 5 (50 each) | Unlimited |
| Screener | 5 filters | 15 filters | Unlimited |
| AI Analysis | Overview only | Full access | Full + API |
| Alerts | None | 10 alerts | Unlimited |
| Portfolio | ❌ | ✅ | ✅ + AI Insights |
| Data Export | ❌ | CSV | CSV + API |
| Reports | Summaries | Full access | Full + Email |

## 🔧 Technical Stack

**Frontend:** React + TypeScript + TailwindCSS

**Database:** PostgreSQL + Redis + TimescaleDB
**AI:** Claude AI (Anthropic)
**Real-time:** Socket.IO WebSocket
**Payments:** Razorpay
