## Troubleshooting

### Issue 1: "Module not found: puppeteer"

**Solution:**
```bash
cd apps/api
npm install puppeteer pdf-lib
```

### Issue 2: PDF Generation Timeout

**Symptoms:**
- Hangs at "Generating PDF..." for >2 minutes
- No error message

**Debugging:**
```typescript
// In pdfExporter.ts, add:
const browser = await puppeteer.launch({
  headless: false,  // Show browser
  devtools: true,   // Open DevTools
  slowMo: 250,      // Slow down
});
```

Then watch the browser window to see where it hangs.

### Issue 3: Watermark Not Showing

**Check Backend Logs:**
```
[1] 🔒 Adding watermark for PRO tier...
```

If missing, verify:
1. User tier is exactly "PRO" (not "Pro" or "pro")
2. pdf-lib installed: `npm list pdf-lib`

### Issue 4: PDF is Blank or Missing Content

**Check:**
1. `.report-ready` class added to body?
   ```javascript
   // In browser console on report page:
   document.body.classList.contains('report-ready')
   ```

2. print.css loaded?
   ```javascript
   // Check computed styles:
   getComputedStyle(document.querySelector('.navbar')).display
   // Should be: "none" in print mode
   ```

3. Wait time sufficient?
   - Increase `page.waitForTimeout(3000)` to `5000` in pdfExporter.ts

### Issue 5: "Report not found" Error

**Verify:**
1. Stock symbol exists in database:
   ```sql
   SELECT * FROM companies WHERE nse_symbol = 'RELIANCE';
   ```

2. User is authenticated (JWT valid)

3. Report data is populated (not empty sections)
