## 🔧 Technical Architecture

### Data Flow
```
Frontend Request
    ↓
GraphQL Query: generateReport(symbol: "RELIANCE")
    ↓
[1] Authentication Check (JWT)
    ↓
[2] Tier Gate (FREE → Upgrade prompt, PRO/PREMIUM → Continue)
    ↓
[3] Redis Cache Check (30min TTL)
    ↓ (cache miss)
[4] Database Check (reports generated within 24hr)
    ↓ (not found)
[5] Data Aggregator Service
    ├─ Fetch company details
    ├─ Parallel fetch 14+ data sources
    └─ Transform & structure data
    ↓
[6] Create GeneratedReport record in PostgreSQL
    ↓
[7] Cache report in Redis (30min)
    ↓
[8] Log analytics event
    ↓
Return report to frontend
```

### Caching Strategy
- **Redis Cache:** 30 minutes (fast repeat access)
- **Database Cache:** 24 hours (reduce regeneration load)
- **Cache Key:** `report:comprehensive:{symbol}`
- **Invalidation:** Automatic expiry

### Tier Gating
- **FREE:** Returns upgrade prompt with `upgradeRequired: true`
- **PRO:** Full report access (view only)
- **PREMIUM:** Full report access + PDF download

### `generated_reports` Table

| Column | Type | Description |
|--------|------|-------------|
| id | UUID | Primary key |
| symbol | String | Stock symbol (e.g., "RELIANCE") |
| company_id | UUID | Foreign key to companies |
| report_type | Enum | COMPREHENSIVE, QUICK_ANALYSIS, etc. |
| title | String | Report title |
| timeline | JSON | Company timeline with events |
| business_model | JSON | Business model section |
| financials | JSON | 5-year financial summary |
| moat | JSON | Competitive advantages |
| supply_chain | JSON | Supply chain analysis |
| catalysts | JSON | Growth drivers |
| govt_impact | JSON | Government policies impact |
| global_trade | JSON | Export/import/FX exposure |
| risks | JSON | Risk analysis with active flags |
| ai_summary | JSON | AI-generated bull/bear case |
| metadata | JSON | Generation params, model version |
| generation_metrics | JSON | Duration, data sources |
| view_count | Int | Number of views |
| download_count | Int | Number of PDF downloads |
| status | Enum | PENDING, GENERATING, COMPLETED, FAILED |

| expires_at | DateTime | When report expires (24hr) |
| last_accessed_at | DateTime | Last view timestamp |
| generated_by | UUID | User who generated report |

### `report_views` Table

| Column | Type | Description |
|--------|------|-------------|
| id | UUID | Primary key |
| report_id | UUID | Foreign key to generated_reports |
| user_id | UUID | Viewer (nullable for anonymous) |
| ip_address | String | Viewer IP address |
| user_agent | String | Browser/device info |
| viewed_at | DateTime | View timestamp |

## 🔒 Security & Authorization

### Authentication
- JWT token required for all report queries/mutations
- Token extracted from `Authorization: Bearer <token>` header
- User context injected into GraphQL resolvers

### Tier Gating
- FREE users: Return `{ upgradeRequired: true, requiredTier: 'PRO', message: '...' }`
- PRO users: Full access to `generateReport` and `getReport`
- PREMIUM users: Full access + PDF download capability (Phase 4)

### Rate Limiting
- Inherits from existing Fastify rate limiting middleware
- Report generation is expensive - consider adding specific limits
